PUBLISH THE EMAIL BUTTON PAGE FREE WITH GITHUB PAGES

1. Download and unzip this ZIP file.
2. Sign in to https://github.com/ (create a free account if needed).
3. Click + (top right) > New repository.
4. Repository name: zest-email-button. Choose Public, then Create repository.
5. In the repository, choose Add file > Upload files.
6. Upload index.html and click Commit changes.
7. Open Settings > Pages.
8. Under Build and deployment, select Deploy from a branch.
9. Select branch main and folder /(root), then click Save.
10. Wait a few minutes. Your URL will look like:
    https://YOUR-GITHUB-USERNAME.github.io/zest-email-button/
11. Replace the placeholder with your actual GitHub username, test the page, then share its URL.

NOTES:
- The URL does not exist until you publish the page in your GitHub account.
- The page is public; anyone with the link can view the letter.
- The button opens the user's configured email app. Some apps may restrict long mailto messages, so test it before sharing widely.
- The original message is embedded in index.html and can be edited before upload.
